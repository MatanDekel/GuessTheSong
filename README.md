# Guess The Song

משחק בסגנון היטסטר: בוחרים קטגוריה, מנגנים שיר בספוטיפיי, מנחשים את השנה ואז הופכים את הקלף.

קטגוריות: להקות בנים, להקות בנות, מעורבב, קייפופ חפיסה 2, עברית, האהובות של עדן, אנימה (כל הזמנים), אנימה שונן (2015 ועד היום), דיסני מצויר, כוכבי דיסני, האנה ג׳ונאס דמי וסלינה, רוק (1995–2015).
